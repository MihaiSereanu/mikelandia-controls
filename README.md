# VE Mobile

A phone and tablet interface for Foundry VTT, with D&D5e sheets and experimental Warhammer 4e/5e and Shadowdark PC support. Based on [VE Mobile by Silvestrae](https://github.com/Silvestrae/ve-mobile).

## Install

In Foundry Setup, open **Add-on Modules ? Install Module**, paste the appropriate Manifest URL, and click **Install**:

- **Warhammer / Shadowdark / other systems:** `https://github.com/MihaiSereanu/ve-mobile/releases/download/latest/module-experimental.json`
- **D&D5e:** `https://github.com/MihaiSereanu/ve-mobile/releases/download/latest/module.json`

Enable **VE Mobile** in your world's **Manage Modules**. Both manifests install the same module; choose one per instance. Cross-system support is experimental.

Use Foundry's module updater for new builds. Every push to `main` publishes the latest build.
